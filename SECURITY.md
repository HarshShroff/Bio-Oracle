# Security Policy

## Supported Versions

Only the latest version of Bio-Oracle is currently supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

Security is paramount in bioinformatics and drug discovery. If you find a security vulnerability, please do NOT open a public issue.

Instead, please report vulnerabilities by emailing **[EMAIL_ADDRESS]** (or opening a private security advisory on GitHub if possible).

We will acknowledge your report within 48 hours and provide a timeline for a fix. Please include:
- A description of the vulnerability.
- Potential impact.
- Steps to reproduce or a Proof of Concept.

We appreciate your help in keeping Bio-Oracle secure for the research community.
