# Contributing to Bio-Oracle

Thank you for your interest in contributing to Bio-Oracle! We welcome contributions from the community to help advance automated phenotypic screening and neuro-symbolic AI in biology.

## Code of Conduct

Help us keep Bio-Oracle an open and welcoming ecosystem. Please be respectful and professional in all interactions.

## How Can I Contribute?

### Reporting Bugs
If you find a bug, please search our existing issues to see if it has already been reported. If not, open a new issue with:
- A clear, descriptive title.
- Steps to reproduce the issue.
- Your environment details (OS, Python version, hardware).

### Suggesting Enhancements
We are always looking for ways to improve Bio-Oracle. If you have an idea:
- Open an enhancement request issue.
- Explain the benefit of the feature and how it aligns with the project's goal of high-throughput analysis.

### Pull Requests
1. Fork the repository.
2. Create a new branch for your feature or fix (`git checkout -b feature/amazing-feature`).
3. Ensure your code follows the project's style (PEP 8).
4. Add tests if applicable.
5. Commit your changes (`git commit -m 'Add some amazing feature'`).
6. Push to the branch (`git push origin feature/amazing-feature`).
7. Open a Pull Request.

## Development Setup

See the [README.md](README.md) for installation instructions. Use the following to install dev dependencies (if any are added later):

```bash
pip install -e .
```

## Scientific Contributions
If you are contributing a new vision model or statistical method:
- Please provide benchmarks against standard datasets (e.g., BBBC021).
- Ensure any new logic is integrated into the PydanticAI reasoning framework where appropriate.

*Bio-Oracle is a product-focused software asset. We prioritize code quality, reproducibility, and mathematical rigor.*
